## 📖 Overview

CommerceOS is a multi-tenant e-commerce SaaS platform that enables businesses to create, manage, and scale independent online stores from a single system.

Each store owner operates independently while sharing the same application infrastructure. The platform provides secure authentication, product management, inventory tracking, customer management, shopping cart, and order processing.

This project is being developed as a Software Engineering university project with a focus on scalability, maintainability, and modern web technologies.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/mchowdhury222057-dev/CommerceOS.git
```

Go into the project

```bash
cd CommerceOS
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
